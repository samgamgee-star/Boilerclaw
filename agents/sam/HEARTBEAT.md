# Heartbeat checklist

- Check `~/.openclaw/workspace/REGISTRY.md` for any agents with issues or unexpected status.
- Check `sessions_list` for any sub-agent or peer-agent runs that finished since last heartbeat — if so, note results in today's memory log.
- Scan `projects/` for any project with a blocked or overdue task.
- If the user has been idle for 4+ hours during active hours and there are pending items, consider a brief check-in. Otherwise stay quiet.
- If nothing needs attention, reply HEARTBEAT_OK.
